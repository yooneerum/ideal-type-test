이 테스트는 단순히 성격 유형을 맞히는 테스트가 아닙니다.

당신이 무엇을 중요하게 생각하는지,
어떤 사람과 함께 있을 때 가장 편안한지,
그리고 왜 그런 사람에게 마음이 끌리는지를 천천히 들여다봅니다.

수많은 선택과 답변 속에서 하나의 심리 모델을 만들고,
그 모델을 바탕으로 당신에게 가장 잘 어울리는 관계의 모습을 이야기해 드립니다.

정답을 알려주는 테스트가 아니라,
나도 몰랐던 나를 발견하는 여정이 되었으면 합니다.



# 🧠 심리 모델(Mental Model) 기반 이상형 분석

이 프로젝트는 단순히 "어떤 사람을 좋아하는가"를 맞추는 심리테스트가 아닙니다.

사용자의 가치관, 사고방식, 의사결정 방식, 인간관계 패턴 등을 종합적으로 분석하여, **사용자의 심리 모델(Mental Model)** 을 구축하고 이를 바탕으로 장기적으로 잘 맞을 가능성이 높은 이상형과 관계 패턴을 추론하는 심리 분석 서비스입니다.

## ✨ 특징

* **심리 모델 기반 분석**

  * 사용자의 응답을 하나의 성격 유형으로 단순 분류하지 않습니다.
  * 다양한 데이터를 종합하여 사용자가 세상을 어떻게 인식하고 판단하는지를 하나의 심리 모델로 설명합니다.

* **다양한 데이터의 통합 해석**

  * 이전 대화 및 자기 탐색 데이터
  * 7가지 핵심 가치 비교 선택 과정
  * 16가지 잠재 가치 분석
  * 가치 판단 이유 및 응답 원자료

  위 데이터를 각각 독립적으로 해석하지 않고, 서로를 보완하는 증거로 통합하여 분석합니다.

* **근거 중심 추론**

  * 모든 결론은 제공된 데이터에 근거하여 도출됩니다.
  * 추정과 사실을 구분하며, 분석 과정과 근거를 함께 제공합니다.

* **가치관과 성향의 구분**

  * 함께 공유해야 하는 가치관과 서로 달라도 괜찮은 성향을 구분하여 해석합니다.
  * 단순히 "비슷한 사람"이 아닌, 장기적으로 건강한 관계를 형성할 가능성이 높은 궁합을 분석합니다.

* **이상형의 심리 구조 분석**

  * 사용자가 지향하는 이상적인 자기 모습(Self-Ideal)
  * 사용자의 강점과 균형을 이루는 상보성(Complementarity)

  두 가지 관점에서 이상형이 형성되는 심리적 이유를 분석합니다.

## 📋 제공되는 분석 내용

* 핵심 심리 모델(Mental Model)
* 가치 구조 분석
* 이상형의 성격 및 특징
* 이상형이 형성된 심리적 과정
* 호감 및 비호감 요소
* 관계에서 중요하게 여기는 가치
* 장점이 단점으로 작용하는 상황
* 장기적으로 잘 맞는 이유와 충돌 가능성
* 연애 및 결혼 단계별 관계 패턴
* 종합 평가 및 심층 관찰 노트

## 🎯 프로젝트 목표

이 프로젝트의 목표는 사용자를 특정 성격 유형으로 분류하거나 평가하는 것이 아닙니다.

대신, 다양한 데이터 속에서 일관된 심리 모델을 구축하고, 그 모델을 통해 사용자가 어떤 관계에서 안정감과 만족을 느끼는지 깊이 이해하도록 돕는 것을 목표로 합니다.

심리 모델은 고정된 결과가 아니라, 새로운 정보가 추가될수록 지속적으로 수정되고 정교해지는 하나의 가설(Model)로 다루어집니다.
